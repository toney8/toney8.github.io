📴 离线就绪清单

Python 运行时（Pyodide / CPython 的 WebAssembly 版，含常用标准库）约十几 MB，第一次打开本页时请保持联网，点上面的按钮等它变绿。之后浏览器会把它留在缓存里，断网打开 App 也能跑代码。若长期不用或清理了浏览器数据，重新联网打开一次即可恢复。「添加到主屏幕」后存储更不易被系统清理。

💾 进度导出 / 导入（换设备接续）

进度、每道题的代码、streak 都保存在这台设备的浏览器本地。在 Duo 与普通 iPhone 之间切换时：导出一个 JSON 文件，AirDrop 到另一台手机，再在那台手机上导入，即可接上同一份进度。

⌨️ 外接键盘快捷键（IDE）

Tab / Shift+Tab 缩进 / 反缩进 · Cmd 或 Ctrl + Enter 运行测试 · Cmd 或 Ctrl + S 保存代码（也会自动保存）· 回车自动延续缩进。在 Duo 展开的大屏上，左边看题目、右边写代码，接上蓝牙键盘就是一台小笔记本。
